# Sales & Performance Analysis Dashboard — Excel

## Project Overview

This project presents an interactive **Sales & Performance Dashboard built in Microsoft Excel** to analyze business performance across countries, products, and time periods.

The dashboard enables users to explore profit distribution, product performance, and annual sales trends through interactive charts and slicers. It demonstrates how Excel can transform raw business data into meaningful insights that support data-driven decision-making.

## &#x20;Project Objectives

- Analyze profit performance across different countries and products.
- Compare the contribution of individual products to overall performance.
- Track annual units sold and monthly performance trends.
- Build an interactive dashboard for business reporting.
- Demonstrate practical Excel data analysis and visualization skills.

## &#x20;Dashboard Features

### 1. Profit by Country and Product

A clustered column chart compares product-level profit across countries, helping identify geographical differences in product performance.

### 2. Annual Units Sold

A column chart compares total units sold between years, making year-over-year volume changes easier to identify.

### 3. Product Performance Distribution

A pie chart visualizes the relative contribution of different products to the selected performance measure.

### 4. Monthly Performance Trend

A line chart displays monthly totals, helping reveal changes in performance throughout the year.

### 5. Interactive Filters

Excel slicers and a date timeline allow users to filter the dashboard by:

- Country
- Product
- Date and reporting period

These interactive controls make it possible to investigate specific segments without manually filtering the underlying data.
